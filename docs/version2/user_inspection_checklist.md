# User inspection checklist

- Confirm that `Snakefile` remains the protected Version 1 thesis workflow controller.
- Confirm that `Snakefile.v2` is the only Version 2 development workflow controller.
- Confirm that `config/config_v2.yaml` points to the intended protected Version 1 inputs.
- Confirm that all Version 2 result outputs are under `results/version2/`.
- Confirm that all Version 2 documentation outputs are under `docs/version2/`.
- Confirm that existing thesis-pipeline documentation has been moved under `docs/version1/`.
- Inspect representation weights before interpreting weighted consensus evidence.
- Inspect boundary edges and boundary rankings before making thesis-facing claims.
- Treat the probability-dependence graph as a development graph layer, not as a validated biological network.
