# Probability-dependence graph report

The probability-dependence graph is a Version 2 development graph layer.

## Intended terminology

Use:

- probability-dependence graph
- weighted patient-referenced support
- boundary edge
- resolved edge
- uncertain dependence
- bridge-like anchor

Avoid:

- causal graph
- true biological network
- validated interaction network
- diagnostic network

## Scientific status

The graph is not a final biological interaction network. It requires inspection and validation before thesis-facing interpretation.
