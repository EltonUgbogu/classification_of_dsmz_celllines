# Script to Output File Mapping

This document maps each output file in `results/unsupervised/pan_cancer/tumour_mapping/`
to the script that generates it. It also records selected cross-cohort table
outputs that are generated by downstream audit rules.

- **`tumour_to_cellline_rankings.tsv`** → `scripts/score_tumour_cellline_mapping.R`

  - Generated at line 285-287

- **`tumour_mapping_summary.tsv`** → `scripts/score_tumour_cellline_mapping.R`

  - Generated at line 290-292

## Cross-Cohort Graph Audit Tables

The post-resolution edge-support stratification tables are generated by
`scripts/post_resolution_edge_support_stratification.py` through the Snakemake
rules `post_resolution_edge_support_stratification` and
`combine_post_resolution_edge_support_stratification`.

- **`results/tables/NBL_post_resolution_edge_support_stratification.tsv`**
  - One row per NBL cell line.
  - Classifies resolved, recurrent-but-unresolved, union-only, and unsupported
    edge evidence after resolved-neighbour graph construction.

- **`results/tables/BRCA_post_resolution_edge_support_stratification.tsv`**
  - One row per BRCA cell line.
  - Uses the existing union-supported, support-threshold consensus, resolved
    edge, and node tables.

- **`results/tables/RBL_post_resolution_edge_support_stratification.tsv`**
  - One row per RBL cell line.
  - Explicitly includes `RBL_14`, `RBL_7`, `WERI_RB1`, `Y_79`, and `RBL_15`.

- **`results/tables/combined_post_resolution_edge_support_stratification.tsv`**
  - Combined NBL, BRCA, and RBL table.
  - Added to the active pipeline target list.

## Script Execution Order

1. **`score_tumour_cellline_mapping.R`** - Generates core mapping results
2. **`inspect_tumour_mapping.R`** - Generates inspection diagnostics (depends on step 1)
3. **`make_pan_cancer_mapping_figures.R`** - Generates figures (depends on steps 1 & 2)
4. **Manual/External** - Documentation markdown files created separately
