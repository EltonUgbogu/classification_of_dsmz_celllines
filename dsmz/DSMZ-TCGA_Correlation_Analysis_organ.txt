TCGA–DSMZ Correlation Analysis
Require (inputs)
TCGA counts as SummarizedExperiment (.rds)
DSMZ counts table (.rds) with columns: Ensembl_ID, gene_name, Ensembl_ID_with_version, and sample columns
DSMZ metadata (.csv) with sample_name, organ, project_id, etc.
 external purity table (sample, purity)
Config: var_gene_set ∈ {tcga_5k, tcga_10k, all}, min_shared, batch_adjust_method ∈ combat_seq, overlay_tcga_centroids ∈ {TRUE,FALSE}
Ensure (outputs)
DSMZ×TCGA Spearman correlation matrix (+ wide/long CSVs)
Per-sample best matches and organ-constrained assignments
Diagnostic figures (violin + CI + tests, heatmap, stacked bar), UMAP figures (before/after batch, projection)
PCA R² diagnostics
Procedure
Load data
 1.1 Read TCGA SummarizedExperiment → counts matrix TCGA_raw.
 1.2 Read the DSMZ counts table, DSMZ_raw, and metadata, DSMZ_meta.
Normalize identifiers
 2.1 HarmonizeGeneIDs(TCGA_raw): strip Ensembl version suffix; sum duplicated rows.
 2.2 BuildDSMZMatrix(DSMZ_raw): coerce sample columns to numeric; set rownames=Ensembl_ID; sum duplicates; drop all-NA columns.
Align samples
 3.1 AlignMetadata(DSMZ_meta, DSMZ_counts):
intersect sample_name with count columns;
Gene intersection
 4.1 common_genes ← intersect(rownames(TCGA), rownames(DSMZ)).
 4.2 Subset both matrices to common_genes. Warn if < min_shared.
Tumor purity (optional)
 5.1 LoadPurityData(TCGA_SE, purity_file) → numeric vector purity (may be NULL).
 5.2 If purity present, TCGA_adj ← ApplyPurityAdjustment(TCGA, purity):
For each gene: Spearman cor(expr, purity) → FDR (BH).
Drop genes with FDR < 0.01 and rho < −0.4.
Linear model per gene: expr ~ (1 − purity); subtract infiltration effect.
 Else: TCGA_adj ← TCGA.
Cohort means & labels
 6.1 From colData(TCGA_SE), pick first available of project_id, study, disease_type; strip TCGA-.
 6.2 ComputeTCGAMeans(TCGA_SE, TCGA_adj) → matrix TCGA_means (genes×cohorts) and per-sample labels.
Feature selection for correlation
 7.1 SelectVariableGenes(TCGA_means, var_gene_set) using row IQR (top 5k/10k) or all.
Correlate DSMZ to TCGA
 8.1 ComputeCorrelations(DSMZ, TCGA_means, DSMZ_meta, sel_genes) → matrix Spearman[DSMZ_sample, TCGA_cohort] (pairwise complete obs).
Organ-constrained mapping
 9.1 Define organ→TCGA code map (e.g., Breast→BRCA; Adrenal/SNS→ACC,PCPG; Lymphoid→DLBC; Myeloid/Leukemia→LAML; etc.).
 9.2 For each DSMZ sample:
sanitize organ (fill missing as “Other”);
candidate cohorts = map(organ) ∩ colnames(TCGA_means);
assign tcga_code = argmax correlation over candidates; else NA.
 9.3 Build dsmz_map with sample_id, organ, tcga_code.
Summaries
 10.1 For each DSMZ sample:
best_tcga_overall = cohort with global max rho;
best_rho_overall = max rho;
rho_allowed = rho to organ-constrained tcga_code (or NA).
 10.2 Merge into summary_tbl.
Diagnostics & visualization
 11.1 Violin plot (best rho per sample by organ):
colorblind palette (Okabe–Ito);
overlay mean ± 95% CI;
global Kruskal–Wallis; pairwise Dunn tests (BH);
save violin_rho_by_organ.pdf + summary CSV and test results.
 11.2 Heatmap: top 25 DSMZ by best_rho_overall; clustered Spearman vs TCGA cohorts; save PDF.
 11.3 Stacked bar: counts of DSMZ assignments (tcga_code incl. “Unassigned”) per organ;
colorblind palette; embed segment counts and total per bar; save PDF.
UMAP analysis
 12.1 Compute logCPM for concatenated counts.
 12.2 Select UMAP features via var_gene_set.
 12.3 Before batch correction:
PCA diagnostics: R² of dataset factor across top PCs + PC1/PC2 plot; save figure & R² table.
UMAP joint: DSMZ colored by organ, TCGA in gray; optional TCGA centroids; save PDFs.
 12.4 Batch correction (choose by config):
combat_seq: on rounded counts with batch = {DSMZ project_id | TCGA}, group = organ; then logCPM.
combat: on logCPM with model preserving organ.
 12.5 After batch correction: repeat PCA diagnostics and joint UMAP; save.
 12.6 Projection mode: fit UMAP on TCGA only; project DSMZ with umap_transform; plot DSMZ by organ over gray TCGA; save.
Save artifacts
 13.1 Correlations: wide CSV, long CSV, RDS.
 13.2 summary_tbl CSV; DSMZ→TCGA mapping CSV.
Return
spearman_scores, summary_tbl, dsmz_mapping, r2_comparison (PC1/PC2 R² before/after).

Notes & safeguards
All correlations use Spearman (rank-based, robust to scale).
Missing purity → skip adjustment transparently.
NA handling: pairwise.complete.obs in correlations; drop all-NA DSMZ columns.
Batch model includes organ to preserve biological signal.
All plots use colorblind-accessible palettes; figures written under outdir/figs.
