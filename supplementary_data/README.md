# Thesis supplementary data

This directory is the committee-facing release for the active 379-gene ranked marker-source pan-cancer analysis. Start with `feature_space/` for the feature panel, `ranking/` for bidirectional rankings and metrics, `tumour_neighbourhood/` for patient-referenced graph inputs, and `pan_cancer_similarity/` for DSMZ and multicohort graph outputs.

Term-level functional-enrichment results are not reported. The `enrichment/` directory contains the configured query/background manifests and the endpoint-timeout status file.

File sizes and SHA-256 values are recorded under `manifests/`. Raw sequencing data, controlled-access data, and large intermediate expression objects are not redistributed.
