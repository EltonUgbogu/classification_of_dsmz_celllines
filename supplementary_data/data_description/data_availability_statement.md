# Data Availability Statement

At the time this documentation was prepared, the raw/pre-filter patient tumour data used upstream of tumour-purity estimation were not available in the working project directory.

The tumour sample identifiers documented here are therefore the post-threshold tumour-purity-passed samples present in the available analysis objects and used for the reported analysis.

The DSMZ metadata file contains 167 cell-line entries and is exported in full in `dsmz_167_cell_line_metadata.tsv`.

Ongoing RBL and NBL raw-data reconstruction workflows are separate from the reported analysis dataset unless reported figures and tables are regenerated from their verified outputs.
